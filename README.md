# Munchlight public pages

Static support and privacy pages: https://nw-b.github.io/munchlight-support/

Migrated from the existing public Munchlight site on September 4, 2026. Existing rendered copy, stylesheet and original croissant artwork preserved; framework runtime scripts removed. No build step, npm dependencies, server or tracking scripts.

Edit index.html, privacy/index.html or style.css locally, commit and push main. GitHub Pages publishes from the repository root. Keep app source, credentials, review contacts and signing files out of this public repository.

The previous site remains available for links embedded in existing app builds. New metadata and future builds use GitHub Pages.
